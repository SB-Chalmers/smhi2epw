Bibliography and source documentation
=====================================

* EnergyPlus. `Auxiliary Programs: EnergyPlus Weather File (EPW) Data
  Dictionary <https://bigladdersoftware.com/epx/docs/26-1/auxiliary-programs/auxiliary-programs.html>`_.
* SMHI. `Open Data portal <https://opendata.smhi.se/>`_ and
  `STRÅNG information <https://strang.smhi.se/>`_.
* Open-Meteo. `Historical Weather API
  <https://open-meteo.com/en/docs/historical-weather-api>`_ and
  `service access and limits <https://open-meteo.com/en/pricing>`_.
* Copernicus Climate Change Service. `ERA5 hourly data on single levels
  <https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels>`_.
* SMHI. `Värmebölja (heat-wave definition)
  <https://www.smhi.se/kunskapsbanken/meteorologi/temperatur/varmebolja>`_.
* Lundström, L. (2012). *Weather data for building simulation: New actual
  weather files for North Europe combining observed weather and modeled solar
  radiation*. Mälardalen University.
* Erbs, D. G., Klein, S. A., and Duffie, J. A. (1982). Estimation of the
  diffuse radiation fraction for hourly, daily and monthly-average global
  radiation. *Solar Energy*, 28(4), 293--302.
* pvlib python 0.16.1. `NREL SPA implementation
  <https://pvlib-python.readthedocs.io/en/v0.16.1/reference/generated/pvlib.solarposition.spa_python.html>`_,
  `extraterrestrial irradiance methods
  <https://pvlib-python.readthedocs.io/en/v0.16.1/reference/generated/pvlib.irradiance.get_extra_radiation.html>`_,
  and `continuous Erbs-Driesse decomposition
  <https://pvlib-python.readthedocs.io/en/v0.16.1/reference/generated/pvlib.irradiance.erbs_driesse.html>`_.
* Reda, I., and Andreas, A. (2004). Solar position algorithm for solar radiation
  applications. *Solar Energy*, 76(5), 577--589.
  `doi:10.1016/j.solener.2003.12.003
  <https://doi.org/10.1016/j.solener.2003.12.003>`_.
* NOAA Global Monitoring Laboratory. `Solar calculation details
  <https://gml.noaa.gov/grad/solcalc/calcdetails.html>`_. Used by the recorded
  pre-pvlib implementation and the independent synthetic provider fixture.
* Alduchov, O. A., and Eskridge, R. E. (1996). Improved Magnus form
  approximation of saturation vapor pressure. *Journal of Applied
  Meteorology*, 35(4), 601--609.
