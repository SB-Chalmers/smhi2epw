The weather files were built with smhi2epw version 1.3.0 (\url{https://github.com/SB-Chalmers/smhi2epw}), which uses the stepwise order with no switch. The results for the stepwise method with a switch to ERA5 (Section\textasciitilde{}\ref{sec:6.6}) were put together from the same runs. The building models were made with EPSM \citep{sbchalmers2026}. The campaign outputs and analysis code will be archived on Zenodo with a DOI on acceptance.
