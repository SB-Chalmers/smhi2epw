# Figures

Put one file per figure here, named by its number in the paper:
`fig01` ... `fig14`, `figC1`, `figC2` (and later ones such as `figA1`).
Use `.pdf` where there is one (vector, preferred) or `.png` (at least 300 dpi).
LaTeX picks the `.pdf` first. A missing file shows a framed placeholder, so the
paper still compiles.

`graphical_abstract.pdf` (or `.png`) fills the Elsevier graphical abstract.
Elsevier asks for at least 1328 x 531 px, readable at 5 x 13 cm.
